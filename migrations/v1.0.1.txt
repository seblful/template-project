This update crossed v1.0.1, which replaces MkDocs with Zensical, hatchling with
uv_build and pre-commit with prek, and trims the defaults:

- mkdocs.yml is gone and zensical.toml replaces it. Port anything you added to
  mkdocs.yml, such as nav entries or extensions, to zensical.toml.
- Preview the docs with `uv run --group docs zensical serve`. The hook that builds
  them is now `zensical`, not `mkdocs`.
- If you added [tool.hatch.*] settings to pyproject.toml, move them to
  [tool.uv.build-backend].
- prek reads the same .pre-commit-config.yaml. Every check now runs with
  `uv run prek run --all-files --hook-stage manual`. The update reinstalled the git
  hooks with prek, removing any .git/hooks/*.legacy files.
- A commit-msg hook now rejects commit messages that are not Conventional Commits.
- The dependency audit runs `uv audit` instead of pip-audit. On GitHub it now fails
  only the weekly scheduled run, so a new CVE no longer blocks pull requests or a
  release; on GitLab, the scheduled pipeline runs the audit alone.
- TODO.md is no longer part of the template. If you kept notes in it, check that
  the update left it in place.
- The config_file question is gone, with config_file.py, its test, config.example.toml
  and the --config option. An unmodified copy is deleted by this update; one you
  changed shows up as a conflict. The README shows how to read a TOML file by
  overriding settings_customise_sources.
- The CLI's `info` command is now `settings`, which prints the settings the program
  would run with as JSON. Commands call `configure(ctx)` first, which is typed.
- The claude_settings question is gone: .claude/settings.json always ships.
- Releasing is its own publish question. It defaults to yes when a license is set,
  as before; answer no to drop release.yml and mark the package Private.
- Ruff selects E, F, W, I, B, UP, SIM, RUF and PT; the stricter families are listed in
  pyproject.toml, commented out. pytest no longer turns warnings into errors or runs
  in random order, and coverage has no minimum. Re-add what you rely on.
- mkdocstrings is gone: docs/reference.md is deleted and the docs are the README,
  built with Zensical alone. The pymdown-extensions cap went with it.
